## ⚙️ Things this has already produced

Real tools running real jobs, not a capability list.

| | |
|---|---|
| **Activity Tracker** | Logs which app and window actually had focus, separating real working time from idle. Blocks distracting apps on a schedule. |
| **IndiaMART Auto-Reply** | Parses buyer name, product and requirement out of new enquiries and sends a tailored quotation within seconds. |
| **Image Generation Pipeline** | Turns a spreadsheet row into a finished creative — layered composition, custom fonts, exported at every size a platform asks for. |
| **[RunPod GPU Pipelines](https://github.com/Sumant-Mourya/RunPod)** | Containerised GPU jobs queued through a serverless endpoint, results filed automatically, pod shut down when the queue empties. |
| **Delivery Status Checker** | Takes a list of tracking numbers, checks each carrier, writes status and last scan back to a sheet. |
| **Invoice & Label Generators** | Numbered GST-style invoices and print-ready shipping labels, batched from an order sheet into one PDF. |
| **[CoC Automation Bot](https://github.com/Sumant-Mourya/Coc-Bot)** | Vision-driven bot that reads the game screen with template matching and acts through ADB. Mostly an excuse to learn computer vision properly. |
| **Ad Video Generator** | Script in, ad out — generates scene footage, synthesises voiceover, stitches the timeline. |
