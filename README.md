### Featured

**[Ios-Dialer](https://github.com/Sumant-Mourya/Ios-Dialer)** — a full replacement dialer for Android

Not a dialpad mockup — a real default-dialer implementation. It binds Android's
`InCallService` and `ConnectionService` to own the entire call lifecycle: incoming
call screens over the lock screen, ongoing-call controls, call log and contacts.

The UI is built on a custom liquid-glass component layer in Compose, and the data
layer uses Room with Paging 3 so contacts and call history stay smooth at any size.

`Kotlin` · `Jetpack Compose` · `Material 3` · `Room` · `Paging 3` · `Telecom API` · `Media3`
