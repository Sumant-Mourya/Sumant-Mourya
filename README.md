### ⭐ Ios-Dialer — a full replacement dialer for Android

Not a dialpad mockup. The app registers as the system's **default dialer** and binds
Android's `InCallService` and `ConnectionService` to own the entire call lifecycle —
incoming call screens over the lock screen, ongoing-call controls, call log and contacts.

The UI sits on a custom **liquid-glass component layer** built in Compose, and the data
layer uses **Room with Paging 3** so contacts and call history stay smooth at any size.
